# Obstacle-detection-system-with-a-3D-lidar
![](https://github.com/WWnotLL/Obstacle-detection-system-with-a-3D-lidar/blob/main/pictures/1790083293.png)

**Всех приветствуем!**   
Мы — команда **«Ящик»**, и представляем вам своё решение задачи **«Система обнаружения посторонних объектов для беспилотных поездов в тоннеле метро по данным 3D-лидара»**.

Наша цель — дать беспилотному поезду возможность заранее заметить препятствие на пути, вовремя подать сигнал об остановке или снижении скорости, минимизируя при этом количество ложных срабатываний.

В этом репозитории собрано всё необходимое для воспроизведения решения: от Docker-образа и исходного кода до описания алгоритма и результатов экспериментов.
